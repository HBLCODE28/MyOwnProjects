# QuickSub 1.0.3

גרסה זו מסתירה את הסיסמה ואת מפתח ה-API, מצפינה את שניהם עבור משתמש Windows הנוכחי ואינה משתמשת בקוד זיהוי נוסף. לאחר השמירה הראשונה אי אפשר להציג, להעתיק או לשנות את הסיסמה מתוך Settings. אפשר להדביק מפתח API חדש כדי להחליף את המפתח הקיים.

# QuickSub

גרסה מתוקנת: תצוגת Dark/Light, תיבות בחירה וקישורי דפדפן.

QuickSub היא אפליקציית WPF ל-Windows שמזהה סדרת טלוויזיה מתוך תיקייה, סורקת את קובצי הפרקים, מחפשת כתוביות ב-OpenSubtitles ושומרת אותן כ-SRT ישירות ליד קובץ הווידאו המתאים.

## מה כלול בפרויקט

- ממשק באנגלית עם מצב Dark כברירת מחדל ומצב Light בהגדרות.
- גרירת תיקיית סדרה או עונה אל החלון.
- תמיכה בשמות סדרות בכל שפה ובתווי Unicode.
- חיפוש סדרה ב-TVmaze והצגת פוסטרים כאשר קיימות כמה התאמות.
- הצגת פוסטר ושם הסדרה במסך הראשי.
- זיהוי שמות פרקים בפורמטים S01E01, S01E01E02 ו-1x01.
- דילוג בטוח על שמות קבצים שלא מכילים מספר עונה ופרק.
- בדיקת פרקים שחסרים בדיסק והצגת פרקים עתידיים בנפרד.
- חיפוש כתוביות לפי hash, סדרה, עונה ופרק.
- דירוג תוצאות לפי hash, התאמת release, אמינות ומספר הורדות.
- הורדה אוטומטית כאשר נמצאה כתובית לכל קובץ.
- הצגת חלון קצר כאשר חסרות כתוביות.
- אפשרות לבחור כתובית חלופית.
- טיפול בכתוביות קיימות: Keep all, Replace all או Review individually.
- המרת ASS, SSA ו-VTT ל-SRT.
- דילוג על כתוביות תמונה כגון SUP ו-PGS.
- שמירת הסיסמה ומפתח ה-API באמצעות Windows Data Protection API עבור משתמש Windows הנוכחי.
- קובץ log טכני תחת `%LocalAppData%\QuickSub\Logs`.
- פרופיל פרסום לקובץ EXE יחיד ועצמאי ל-Windows x64.
- סקריפט Inno Setup ליצירת מתקין עם קיצור דרך בשולחן העבודה.

## דרישות לפיתוח

1. Windows 10 או Windows 11 ב-64-bit.
2. Visual Studio 2022 מעודכן.
3. במהלך התקנת Visual Studio יש לסמן את workload בשם `.NET desktop development`.
4. .NET 8 SDK.
5. חשבון OpenSubtitles.com ומפתח API.
6. Inno Setup 6 רק לצורך יצירת קובץ המתקין.

## פתיחת הפרויקט ב-Visual Studio

1. חלצי את קובץ ה-ZIP לתיקייה רגילה.
2. פתחי את `QuickSub.sln`.
3. אם Visual Studio מבקש להתקין את .NET 8 או את workload של Desktop, אשרי את ההתקנה.
4. ודאי שבסרגל העליון מוגדר `Debug` ו-`Any CPU`.
5. לחצי `F5` כדי להריץ עם Debug, או `Ctrl+F5` כדי להריץ בלי Debug.

אין צורך להתקין חבילות NuGet חיצוניות. הפרויקט משתמש רק ברכיבי .NET ו-Windows.

## יצירת חשבון ומפתח OpenSubtitles

1. הפעילי את QuickSub.
2. בהפעלה הראשונה ייפתח מסך Settings.
3. לחצי `Create account` כדי לפתוח את עמוד ההרשמה של OpenSubtitles.com.
4. לאחר כניסה לחשבון, לחצי `Open API key page`.
5. צרי consumer או API key בחשבון.
6. הדביקי את המפתח לשדה `API key`. השדה מוסתר ואינו מאפשר להעתיק את המפתח מתוכו.
7. הזיני שם משתמש וסיסמה.
8. לחצי `Test connection`.
9. לאחר הצלחה לחצי `Save`.
10. לאחר השמירה הראשונה הסיסמה ננעלת ולא ניתן להציג, להעתיק או לשנות אותה מתוך Settings. מפתח ה-API נשאר מוסתר; כדי להחליף אותו, הדביקי מפתח חדש בשדה והשאירי אותו ריק כדי לשמור את המפתח הקיים.

המפתח אינו כלול בקוד ואסור לפרסם מפתח פרטי בתוך GitHub או בתוך EXE שמופץ לאחרים. כל משתמש מזין את פרטי החשבון והמפתח שלו.

## שימוש באפליקציה

1. גררי את תיקיית הסדרה, תיקיית העונה או תיקייה שמכילה פרקים ישירות אל החלון.
2. QuickSub תנקה חלקים כמו `S01`, `1080p`, `WEB-DL` ו-`Complete` משם התיקייה לצורך החיפוש בלבד.
3. כאשר קיימות כמה סדרות אפשריות, לחצי על הפוסטר המתאים.
4. במסך הראשי יוצגו הפוסטר, שם הסדרה ומספר קובצי הווידאו שזוהו.
5. לחצי `Scan subtitles`.
6. אם קיימות כתוביות, בחרי Keep all, Replace all או Review individually.
7. אם נמצאו כתוביות לכל הפרקים, ההורדה תתחיל אוטומטית.
8. אם חסרות כתוביות, יוצג סיכום קצר עם Download available, Review results ו-Cancel.

## מבנה הפלט

אם קובץ הווידאו נמצא כאן:

```text
Breaking Bad\Season 01\Breaking.Bad.S01E01.1080p.WEB-DL.mkv
```

הכתובית תישמר כאן:

```text
Breaking Bad\Season 01\Breaking.Bad.S01E01.1080p.WEB-DL.en.srt
```

הכתובית נשמרת באותה תיקייה של קובץ הווידאו, עם אותו שם בסיס ותוספת קוד השפה.

## מגבלת שמות קבצים

QuickSub תומכת בשמות שמכילים:

```text
Show.Name.S01E01.mkv
Show.Name.S01E01E02.mkv
Show.Name.1x01.mkv
```

קובץ כגון `Episode 1.mkv` או `01.mkv` יידלג. זו החלטה מכוונת כדי לא להוריד כתובית לפרק הלא נכון.

## יצירת EXE עצמאי מתוך Visual Studio

1. לחצי לחיצה ימנית על הפרויקט `QuickSub` ב-Solution Explorer.
2. בחרי `Publish`.
3. בחרי את פרופיל `Portable` הקיים בפרויקט.
4. לחצי `Publish`.
5. הקובץ ייווצר בנתיב:

```text
QuickSub\bin\Release\net8.0-windows\win-x64\publish\QuickSub.exe
```

הקובץ הוא Self-contained, ולכן במחשב היעד אין צורך להתקין .NET בנפרד.

אפשר גם לפתוח PowerShell בתיקיית הפרויקט ולהריץ:

```powershell
.\Scripts\Publish-Portable.ps1
```

הסקריפט ייצור גם:

```text
Artifacts\Portable\QuickSub.exe
Artifacts\QuickSub-Portable.zip
```

## יצירת מתקין

1. התקיני Inno Setup 6.
2. הריצי את:

```text
Scripts\Build-All.bat
```

או מתוך PowerShell:

```powershell
.\Scripts\Build-Installer.ps1
```

קובץ ההתקנה ייווצר בתוך:

```text
Installer\Output\QuickSub-Setup-1.0.3.exe
```

המתקין מתקין את QuickSub עבור המשתמש הנוכחי, יוצר קיצור דרך בתפריט ההתחלה ומסמן כברירת מחדל יצירת קיצור דרך בשולחן העבודה.

## אבטחת פרטי OpenSubtitles

- אין קוד זיהוי נוסף ואין מסך "Verifying it is you".
- הסיסמה ומפתח ה-API מוצפנים באמצעות Windows עבור משתמש Windows הנוכחי.
- הסיסמה מוזנת רק בהגדרה הראשונה. לאחר השמירה היא מוצגת כשדה נעול ומוסתר, ואי אפשר לשנות אותה מתוך Settings.
- מפתח ה-API השמור לעולם אינו נטען לתוך שדה התצוגה, ולכן אי אפשר להעתיק אותו.
- אפשר להדביק מפתח API חדש בשדה המוסתר כדי להחליף את המפתח הקיים. שדה ריק משאיר את המפתח הקיים.
- כדי לאפס גם את הסיסמה, מחקי את `%LocalAppData%\QuickSub\settings.json` והפעילי את QuickSub מחדש.

## קבצי הגדרות ולוג

הגדרות:

```text
%LocalAppData%\QuickSub\settings.json
```

לוגים:

```text
%LocalAppData%\QuickSub\Logs
```

ניתן למחוק את תיקיית QuickSub תחת LocalAppData כדי לאפס את כל ההגדרות המקומיות.

## הערות חשובות

- מכסת ההורדות נקבעת על ידי חשבון OpenSubtitles.
- QuickSub מבצעת ניסיונות חוזרים אוטומטיים בשגיאות זמניות וב-HTTP 429, אך אינה עוקפת מגבלות חשבון.
- המרת ASS או SSA ל-SRT מסירה עיצוב מתקדם, צבעים ומיקום טקסט. הטקסט והתזמון נשמרים.
- כתוביות מבוססות תמונה אינן מומרות באמצעות OCR ולכן מדולגות.
- TVmaze משמש לזיהוי הסדרה ולרשימת הפרקים. OpenSubtitles משמש לחיפוש ולהורדה.

## תיקון תצוגה וקישורי OpenSubtitles

בגרסה זו נוסף תיקון מפורש לרקע ולצבע הטקסט בכל חלונות האפליקציה. התיקון מונע מצב שבו חלון WPF מותאם אישית מקבל רקע לבן של Windows בזמן שהטקסט נשאר בצבע של ערכת Dark.

גם תיבות הבחירה קיבלו תבנית מלאה שמתאימה לערכות Dark ו-Light.

הכפתורים `Create account` ו-`Open API key page` מנסים לפתוח את דפדפן ברירת המחדל. אם Windows אינו מצליח לפתוח את הקישור בדרך הרגילה, QuickSub מנסה דרך Explorer. אם גם זה נכשל, הכתובת מועתקת ללוח ומוצגת למשתמש.

## תיקיית בדיקה

הקובץ הנפרד `QuickSub-Sample-Series.zip` מכיל תיקייה בשם:

```text
Breaking.Bad.S01.Complete
```

ובתוכה שלושה קובצי וידאו סינתטיים:

```text
Season 01\Breaking.Bad.S01E01.WEB-DL.mkv
Season 01\Breaking.Bad.S01E02.WEB-DL.mkv
Season 01\Breaking.Bad.S01E03.WEB-DL.mkv
```

הקבצים אינם פרקים אמיתיים ואינם כוללים תוכן מוגן. הם כוללים תבניות וידאו שנוצרו לצורך בדיקת זרימת העבודה. גררי את התיקייה הראשית אל QuickSub. האפליקציה אמורה לזהות את הסדרה Breaking Bad ואת שלושת מספרי הפרקים. התאמת hash לא תהיה התאמה של מהדורת פרק אמיתית, ולכן החיפוש ימשיך לפי הסדרה, העונה והפרק.
