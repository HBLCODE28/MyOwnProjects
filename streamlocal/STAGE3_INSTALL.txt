STREAMLOCAL - STAGE 3 BROWSER-ONLY MIGRATION

This Stage changes the architecture. It removes the Python/FastAPI/SQLite runtime
and moves StreamLocal library data into IndexedDB in the browser.

1. Extract this ZIP directly into the existing StreamLocal project directory.
   Choose Replace/Merge when Windows asks.

2. Open PowerShell in:
   C:\Users\Cyber_User\Documents\Projects\streamlocal

3. Run:
   powershell -ExecutionPolicy Bypass -File .\stage3-browser-apply.ps1

The script:
- requires Stage 2 COMPLETE,
- installs browser-only npm dependencies,
- runs Vitest tests,
- runs TypeScript checks,
- builds the static PWA,
- verifies there are no backend API calls in src/,
- removes the old backend directory from Git/project,
- updates STAGES.md Stage 3,
- commits:
  Stage 3: browser-only media recognition

After success:
powershell -ExecutionPolicy Bypass -File .\scripts\dev.ps1

Then:
- Library -> Add folder
- Identify -> Identify library
- Settings -> Export library

The old SQLite database in %LOCALAPPDATA%\StreamLocal is not deleted.
