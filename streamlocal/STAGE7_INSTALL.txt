STREAMLOCAL - STAGE 7

This package includes the fixes requested after Stage 6:

- Fixes the Home Hero mixing a movie title/type with a series overview.
- Series Hero now uses one consistent Series entity.
- TVmaze series cards prefer horizontal background/banner artwork.
- Images use object-fit: cover, so they fill cards without stretching.
- Clicking a series opens a Netflix-style Series Hub overlay.
- Choose a season.
- Browse individual episodes.
- Play the selected local MP4/MKV episode.

INSTALL

1. Extract this ZIP into:
   C:\Users\Cyber_User\Documents\Projects\streamlocal

2. Choose Replace/Merge.

3. Run:
   powershell -ExecutionPolicy Bypass -File .\stage7-browser-apply.ps1

4. After success:
   powershell -ExecutionPolicy Bypass -File .\scripts\dev.ps1

IMPORTANT AFTER STARTING THE SITE

Because old TVmaze matches may only have stored portrait poster URLs, go to:

Settings
-> Find series posters with TVmaze

Run it once again. Stage 7 will then fetch TVmaze image lists and store horizontal
background/banner URLs when available.

CHECK

- Home Hero title/type/overview all belong to the same series/movie.
- Series cards are horizontal and not squeezed.
- Click Breaking Bad / Stranger Things / etc.
- Series Hub opens.
- Change Season.
- See episode rows.
- Click Play on an episode.
