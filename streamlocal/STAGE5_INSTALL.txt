STREAMLOCAL - STAGE 5

This package adds:
- Direct local MP4 playback.
- Custom player overlay and keyboard shortcuts.
- Fullscreen, seek, volume and playback speed.
- Encrypted local API-key vault for future poster/metadata integrations.

1. Extract this ZIP into the existing StreamLocal project directory.
   Choose Replace/Merge.

2. Run:
   powershell -ExecutionPolicy Bypass -File .\stage5-browser-apply.ps1

3. After success:
   powershell -ExecutionPolicy Bypass -File .\scripts\dev.ps1

Browser checks:
- Click an available MP4 movie.
- Test Play/Pause, seek, volume, speed and fullscreen.
- Test Space/K, J/L, arrows and F.
- Settings -> Encrypted API keys.
- Create a vault password (8+ characters).
- Save a TMDb Read Access Token or API Key.
- Lock and unlock the vault.
- Export Library and confirm API credentials are not part of the backup.

MKV playback remains Stage 6.
