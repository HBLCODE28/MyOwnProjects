# StreamLocal

StreamLocal is a Windows local-first movie and TV library/player that runs through a local web application.

## Project documents

- `SPEC.md` - full product and technical specification.
- `STAGES.md` - authoritative implementation stages and progress tracker.

## Repository layout

- `frontend/` - React + TypeScript frontend.
- `backend/` - FastAPI backend.
- `scripts/` - Windows development/build scripts.
- `tools/` - local tool integration such as FFmpeg.
- `docs/` - architecture and implementation documentation.
- `data/` - placeholder only. Runtime data must not be committed.

## Development status

Development follows `STAGES.md`. Do not begin a later Stage until the current Stage acceptance criteria pass.
