STREAMLOCAL - STAGE 8

This ZIP includes the requested fixes plus the full next stage:

UI fixes
- Series Hub uses the main StreamLocal navigation instead of a second navigation bar.
- Hub close control is a compact X rather than a second text bar.
- Series Hub starts below the main navbar.
- Series Hub artwork uses contain to avoid extreme zoom/cropping.

Movie artwork
- Settings -> Find movie posters with Wikipedia.
- No account/API key required.
- Only movie title/year are sent.
- Local artwork remains higher priority.

Playback/history
- Position is saved every few seconds and on pause/close.
- Unfinished playback resumes automatically.
- Home gets Continue Watching.
- Progress bars and Watched badges are displayed.
- Watched rules:
  Movie: >=90% OR <=5 minutes remaining.
  Episode: >=90% OR <=2 minutes remaining.
