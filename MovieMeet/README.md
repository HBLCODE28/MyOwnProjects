# MovieMeet

אפליקציית PHP + MySQL לקביעת סרט עם חברים.

## הפעלה

1. צרו מסד MySQL בשם `moviemeeet` או בחרו שם אחר והגדירו אותו בקובץ ההגדרות.
2. העתיקו את `htdocs/api/config.php.example` אל `htdocs/api/config.php` ועדכנו את פרטי מסד הנתונים.
3. הגדירו `MOVIEMEET_TMDB_TOKEN` לחיפוש סרטים ו־`MOVIEMEET_GOOGLE_MAPS_API_KEY` לחישוב זמני נסיעה אמיתיים. ללא מפתח, האתר משתמש בהערכת מרחק בסיסית.
4. הגדירו את שורש האתר ל־`htdocs/`.

הטבלאות ומאגר הקולנועים נוצרים אוטומטית בחיבור הראשון למסד הנתונים.
