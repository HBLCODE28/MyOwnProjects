# Hila Playground – העלאה ומטמון

## כלל חובה בסיום שינוי

בכל שינוי שמשפיע על קובץ שמוגש לדפדפן בפרויקט
`h1la-playground/h1la-playground` (כגון HTML, CSS או JavaScript), יש להגדיל
את מזהה הגרסה בשלוש כתובות הנכסים ב־`index.html`:

- `styles.css?v=...`
- `projects.js?v=...`
- `app.js?v=...`

המזהים צריכים להיות זהים וחדשים ביחס לגרסה הקודמת. כך העלאה ידנית לשרת
מאלצת את הדפדפן ואת ה־CDN לבקש קבצים מעודכנים במקום להשתמש בעותק שמור.

## בעת העלאה

יש להעלות לפחות את `index.html` ואת כל קובץ נכס שהשתנה באותו עדכון.
