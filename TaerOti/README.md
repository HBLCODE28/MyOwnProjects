# תאר אותי — PHP

משחק RTL למובייל ולמחשב, ללא Node.js וללא מסד נתונים. מצב המשחק נשמר בקובץ JSON לכל חדר תחת `data/`, עם נעילת קובץ כדי למנוע דריסת פעולות מקבילות. הדפדפנים מתעדכנים בפולינג קצר ל־`api.php`.

## פריסה

העלו את כל תיקיית `TaerOti` ל־document root של אתר PHP. דרושה PHP 8.1 ומעלה עם הרחבות `json`, `mbstring` ו־`random` הפעילות. תנו למשתמש של שרת האינטרנט הרשאת כתיבה לתיקיית `data/`; אל תאפשרו גישה ישירה אליה (הקובץ `data/.htaccess` כבר חוסם זאת ב־Apache).

ה־web root חייב לתמוך ב־PHP וב־HTTPS. אין צורך ב־Node, npm, Redis, Socket.IO או WebSocket.

## מה ממומש

- יצירת חדר וקוד כניסה אקראי של 8 תווים (כ-40 ביט), ללא I/O/0/1 כדי לצמצם טעויות הקלדה
- הגבלת ניסיונות של קוד חדר שגוי: לאחר 8 ניסיונות שגויים בתוך דקה ההצטרפות הידנית נחסמת זמנית
- שיתוף הזמנה דרך כפתור "שתף משחק" בלי להציג את ה-URL בממשק, עם הודעת הזמנה קצרה ואימוג'ים ליד הקישור
- בטלפון, כאשר Web Share זמין, הכפתור פותח את חלון השיתוף של המכשיר; ב-HTTP מקומי או בדפדפן ללא Web Share ההזמנה מועתקת ללוח
- הצטרפות ללא חשבון
- משחק יכול להתחיל רק כאשר יש לפחות 4 משתתפים מחוברים בחדר
- QR חזר ללובי המארגן ומוצג גם במחשב וגם בטלפון; הוא מפנה ישירות לקישור ההזמנה
- הזנת קוד חדר במובייל גוללת את השדה לאזור הגלוי ומוסיפה מרווח מול המקלדת כדי שהקוד לא יוסתר
- כותרת הלובי ממורכזת
- אפשרות QA הוסרה לחלוטין מהממשק ומהשרת
- פריסת Desktop צומצמה למשטח של כ-1080x760 לכל היותר, שמתאים בנוחות למסך 1920x1080
- בחירת דמות עקבית מתוך דמויות נשים, גברים, ילדים ומבוגרים
- המארגן מופיע ברשימת המשתתפים ומשתתף במשחק
- Browser session באמצעות cookie מסוג HttpOnly: רענון או טאב נוסף באותו דפדפן מתחברים לאותו participant ולא יוצרים כפילות
- מניעת שמות כפולים בחדר
- בחירת מספר סבבים עם מגבלת n-1 ו-Popup שמסביר למה אי אפשר לעבור את המגבלה
- שיבוץ יעד שונה לכל משתתף בכל סבב
- מניעת חזרה על אותו זוג מתאר -> יעד, עם fallback אם אין פתרון
- שלב הכנה של 60 שניות
- כל משתתף יכול ללחוץ "התחל משחק"; כאשר כולם מוכנים המשחק מתקדם מיד
- תורים אוטומטיים של 10 שניות
- אם כל המשתתפים הזכאים לנחש כבר בחרו לפני סוף הטיימר, התור נסגר מיד ועוברים אוטומטית לתור הבא
- בכל מעבר לתור חדש נשמע אצל המארגן בלבד ג'ינגל קצר; אצל המשתתפים אין צליל מעבר
- ניחוש מכל המכשירים, כולל אפשרות ליעד לנחש את עצמו
- שם שכבר נבחר מוסר מאפשרויות הניחוש של אותו משתמש להמשך הסבב
- היעד האישי של המשתמש נשאר מוצג ברשימת הניחוש אך חסום ללחיצה, ללא תווית שמסבירה למה
- המשתתף שמתאר כרגע נשאר מוצג ברשימת הניחוש אך חסום ללחיצה, וגם השרת דוחה ניסיון לבחור בו
- אם נשארת אפשרות חוקית אחת בלבד, השרת בוחר אותה אוטומטית ומציג למשתמש הודעה קצרה
- Fastest finger: רק הניחוש הנכון הראשון מקבל נקודות
- ניקוד: מנחש ראשון +2, מתאר +1 אם ניחשו, מתאר +3 אם לא ניחשו
- חשיפת התשובות רק בסוף הסבב
- טבלת ניקוד סבבית ומצטברת
- מסך סיום עם Leaderboard, כל הזיווגים ומפת חברויות
- בסיום המשחק המארגן יכול ליצור משחק חדש עם אותם משתתפים; כולם חוזרים יחד ללובי והניקוד והזיווגים מתאפסים
- התראת ניתוק נשלחת למארגן מיד כאשר Socket.IO מזהה שמשתתף התנתק; heartbeat מהיר יותר מקצר גם זיהוי של ניתוק רשת שקט
- אם המארגן מתנתק, כל המשתתפים רואים התראה. אם הוא לא חוזר בתוך 10 שניות, הניהול עובר למשתתף המחובר הבא לפי סדר ההצטרפות והחדר נשאר פעיל
- Fullscreen אוטומטי ככל שהדפדפן מאפשר
- פונט אחיד בכל האתר, במובייל וב-Desktop: Arial עם fallback ל-Helvetica

## Session

כל משתתף מזוהה באמצעות PHP session עם cookie מסוג HttpOnly. רענון באותו דפדפן מחזיר לאותו משתתף. בלי הרשמה או חשבון אין אפשרות לזהות אותו אדם בדפדפן אחר.

## אבטחת ההזמנה

- הקוד של החדר אקראי באורך 8 תווים, ושמות כפולים נחסמים.
- פעולות משחק מאומתות בצד השרת מול ה־session של המשתתף.
- מצב חדר נכתב תחת נעילת קובץ, ותיקיית הנתונים חסומה מגישה ישירה ב־Apache.
- לפריסה אמיתית באינטרנט יש להשתמש ב־HTTPS.

## שיתוף בטלפון

Web Share API דורש בדרך כלל secure context. בפריסה עם HTTPS, "שתף משחק" פותח את חלון השיתוף של הטלפון וניתן לבחור WhatsApp, Telegram, SMS וכו'. בהרצה מקומית דרך `http://<LAN-IP>:3000`, אם הדפדפן לא מאפשר Web Share, הטקסט והקישור מועתקים ללוח במקום להציג URL על המסך.

## Fullscreen

Chrome ודפדפנים אחרים אינם מאפשרים לאתר להיכנס ל-Fullscreen בזמן טעינת העמוד ללא פעולה של המשתמש. לכן במובייל הבקשה מתבצעת בפעולת המשתמש הראשונה ובכפתורי הפעולה המרכזיים. ב-iPhone הדרך היציבה להסיר את ממשק Safari היא Add to Home Screen ולהפעיל את ה-PWA מהאייקון.
